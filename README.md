# Code Crew

A minimal, cinematic website starter for Code Crew.

## Run locally / in StackBlitz

1. Open this repository in your coding environment.
2. Add the files from this starter, preserving their folder paths.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the preview on the provided local development port.

## Scroll-controlled hero video

The hero is already wired to use a silent MP4 at:

`public/media/code-crew-hero.mp4`

Until that file exists, a CSS-built visual placeholder appears instead. When the MP4 is added, the scroll position scrubs through its timeline.

For best results, use a short, compressed H.264 MP4 without audio. See `public/media/README.md`.

## Before launch

- Replace the contact email if you choose a different address.
- Confirm the production domain in `app/layout.tsx`.
- Add real project examples and approved business details.
- Add the final favicon and social sharing image.
- Connect the contact form to a backend or email service before advertising it as a working submission form.

The current contact link opens an email draft; it does not store form submissions.
