Place the final, compressed MP4 hero video in this folder and name it:

code-crew-hero.mp4

The scroll-controlled hero expects this exact path:
public/media/code-crew-hero.mp4

Recommended source:
- H.264 MP4
- 1920x1080 or 1280x720
- 24 or 30 fps
- 6–12 seconds
- No audio (the page is designed to be silent)
- Keep the file as small as practical; aim for roughly 3–8 MB

The video should be designed as a continuous visual sequence with a clear beginning, middle and ending. The website currently displays an animated CSS fallback until the MP4 is added.
